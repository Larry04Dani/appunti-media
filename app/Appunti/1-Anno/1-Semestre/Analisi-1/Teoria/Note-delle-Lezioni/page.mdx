# Valore assoluto o modulo

$$
|a| = 
\begin{cases}
  a & \text{se } a \ge 0 \\
  -a & \text{se } a < 0
\end{cases}
$$

$$
|a+b| = |a|+|b|
$$

# Intervalli
$(a,b) := \{x \in \R : a<x<b\}$
- chiuso $\Rightarrow[a,b]$ L'estremo è incluso nell'insieme
- aperto $\Rightarrow (a,b)$ L'estremo non è incluso nell'insieme

# Proprietà di densità di $\Q$ in $\R$ e di $\R \setminus \Q$

- se $a,b \in \R \land a<b \Rightarrow \exist c \in \Q : c \in (a,b)$

# carattterizzazione di $sup(A)$ per $A \subset \R$ Limitato superiormente  
$c \in \R$ allora $c = sup(A) \Leftrightarrow \forall a \in A,  c \geq a \land \forall \epsilon > 0, \exist a \in A : a>c-\epsilon $
