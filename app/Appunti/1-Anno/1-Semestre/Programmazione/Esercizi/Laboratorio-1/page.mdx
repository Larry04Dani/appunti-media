## Es 1

Ricopiare/riscrivere e poi compilare i due semplici programmi proposti in aula (di scrittura su schermo e somma di due variabili).
- Scrivere un programma che scrive sullo schermo "Benvenuti al corso di programmazione in C".
- Scrivere un programma che assegna dei valori a due variabili intere e poi calcola e stampa la loro somma.

<Spoiler>
```c
#include <stdio.h>

int main(void)
{
    int a, b, somma;
    a = 2;
    b = 3;
    somma = a+b;
    printf("Benvenuti al corso di programmazione C\n");


    printf("2 + 3 = %d\n",somma);

    return 0;
}
```
</Spoiler>

## Es 3
<Spoiler>
Scrivere un programma che richiede all'utente di inserire due numeri interi e poi calcola e stampa la loro somma, differenza, prodotto e risultato della divisione.
```c
#include <stdio.h>
int main (void)
{
    int a,b, somma, differenza, prodotto;
    float divisione;
    printf("inserisci il valore di a: ");
    scanf("%d",&a);
    printf("inserisci il valore di b: ");
    scanf("%d",&b);
    somma = a+b;
    differenza = a-b;
    prodotto = a*b;
    divisione = (float) a/b;
    printf("la somma è: %d\n", somma); 
    printf("la differenza è: %d\n", differenza); 
    printf("il prodotto è: %d\n", prodotto); 
    printf("la divisione è: %.2f\n", divisione); 
}
```
</Spoiler>
