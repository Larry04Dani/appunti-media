## Es 1

Scrivere un programma che prende in input un numero positivo N
e scrive in output il valore di n!. Il programma deve definire e utilizzare una funzione ricorsiva int fatt(int) per calcolare tale numero.

<Spoiler>
```c
#include <stdio.h>

int fatt(int a)
{
    if (a == 1) return 1;
    return a * fatt(a-1);
}

int main(void)
{
    int n;
    printf("Inserisci l'argomento\n");
    scanf("%d",&n);
    printf("%d! è uguale a: %d\n",n,fatt(n));
}
```

## Es 4

L'algoritmo di Euclide si basa sulle seguenti proprietà:
- Caso base: se b == 0, il MCD è a.
- Caso ricorsivo: altrimenti, il MCD di a e b è uguale al MCD di b e a % b.
Scrivere un programma che prende in input due numeri positivi x e y
e scrive in output il loro massimo comun divisore. Il programma deve definire e utilizzare
una funzione ricorsiva int MCDricor(int) che usa l'algoritmo di Euclide per calcolare tale numero.

<Spoiler>
```c
#include <stdio.h>

int MCD(int a, int b)
{
    if(b == 0) return a;
    return MCD(b, a % b);
}

int main(void)
{
    int x, y;
    printf("Inserisci i numeri di cui vuoi calcolare MCD\n");
    scanf("%d",&x);
    scanf("%d",&y);
    printf("%d",MCD(x,y));
}
```
</Spoiler>

## Es 5

*Numeri di Fibonacci.*
Riprendere dall'esercizio lab07_4 la funzione iterativa e definire anche una funzione ricorsiva 
per il calcolo dei numeri di fibonacci. Nel main richiedere all'utente di inserire un numero per calcolare 
il relativo numero di fibonacci e poi eseguire prima la versione iterativa e poi quella 
ricorsiva per notare la differenza di velocità di calcolo.

<Spoiler>
```c
#include <stdio.h>

int FibonacciRic(int n)
{
    if (n == 1) return 1;
    if (n == 0) return 0;
    return (FibonacciRic(n-1) + FibonacciRic(n-2));
}
int FibonacciIte(int n)
{
    int precedente = 0, attuale = 1;
    for(int i = 1; i < n; i++)
    {
        attuale = attuale + precedente;
        precedente = attuale - precedente;
    }
    return attuale;
}
int main(void)
{
    int n;
    printf("Inserire l'n-numero da calcolare\n");
    scanf("%d",&n);
    printf("Fibonacci ricorsivo: %d\n",FibonacciRic(n));
    printf("Fibonacci iterativo: %d\n",FibonacciIte(n));

}
```

## Es 6

*Ho fatto un sogno in cui una fatina dai capelli turchini mi dava un numero del lotto. 
Decido di giocare questo numero alle estrazioni del lotto della ruota di Roma: 
1 Euro ogni settimana per un anno intero (52 settimane).*

Scrivere un programma per simulare la situazione e stabilire quanto vinco/perdo sapendo che:
- Nella ruota di Roma vengono estratti 5 numeri distinti tra 1 e 90
- La vincita per aver indovinato un numero, avendo giocato 1 Euro è di 11,23 Euro. (Vedi tutti gli importi su
[lotto-italia.](https://www.lotto-italia.it/lotto/come-dove-giocare/il-gioco/premi-del-lotto) 

NOTA: utilizzare 5 variabili distinte per le 5 estrazioni della ruota di Roma.

<Spoiler>
```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int estrai(int x)
{
    int num1, num2, num3, num4, num5;
    num1 = 1 + rand() % 90;
    do
    {
        num2 = 1 + rand() % 90;
    }
    while(num2 == num1);
    do
    {
        num3 = 1 + rand() % 90;
    }
    while(num3 == num2 || num3 == num1);
    do
    {
        num4 = 1 + rand() % 90;
    }
    while(num4 == num3 || num4 == num2 || num4 == num1);
    do
    {
        num5 = 1 + rand() % 90;
    }
    while(num5 == num4 || num5 == num3 || num5 == num2 || num5 == num1);
    
    if( x == num1 || x == num2 || x == num3 || x == num4 || x == num5)
    {
        return 1;
    }
    return 0;
}


int main(void)
{
    srand(time(NULL));
    float conto = 0;
    int num = 1 + rand()%90;
    for(int i = 0; i < 52; i++)
    {
        conto += estrai(num)? 11.23 : -1;
    }
    printf("Dopo un anno il tuo conto è di: %.2f euro\n",conto);
}
```
</Spoiler>
