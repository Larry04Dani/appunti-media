#### Variabili

##### Esempio grafico
```c
int MyNumber;    //Dichiarazione di una variabile (di tipo: intero)
MyNumber = 10;   //Assegnazione
MyNumber = (MyNumber + 10)/4; //Puoi usare qualunque variabile 
printf("%d",MyNumber) //Specificare il tipo di dato, per interpretarlo

```

#### Tipi di dato
esistono diversi tipi di dato, alcuni tra i più comuni sono:

| *Tipo*  | *Scopo*                 | *Dimensione* |
| ------- | ----------------------- | ------------ |
| `int`   | numero intero           | 4 Bytes      |
| `float` | numero a virgola mobile | 4 Bytes      |
| `char`  | carattere               | 1 Byte       |

<Callout type="attenzione" title="Nota Bene">in realtà la dimensione e l'interpretazione dei tipi può cambiare in base al compilatore o al sistema operativo, esistono tipi di dato particolari che assicurano una dimensione fissa.</Callout>

#### Operatori
##### Operatori aritmetici
Utilizzati per eseguire operazioni matematiche sui dati.

| **Operatore** | **Nome**        | **Descrizione**                                                         | **Esempio.                   a = 10, b = 3** |
| ------------- | --------------- | ----------------------------------------------------------------------- | -------------------------------------------- |
| `+`           | Addizione       | Somma due valori                                                        | `a + b` $\rightarrow$ `13`                   |
| `-`           | Sottrazione     | Sottrae il secondo valore dal primo                                     | `a - b` $\rightarrow$ `7`                    |
| `*`           | Moltiplicazione | Moltiplica due valori                                                   | `a * b` $\rightarrow$ `30`                   |
| `/`           | Divisione       | Divide il numeratore per il denominatore (se interi, tronca i decimali) | `a / b` $\rightarrow$ `3`                    |
| `%`           | Modulo          | Restituisce il resto della divisione intera                             | `a % b` $\rightarrow$ `1`                    |

##### Operatori logici
Utilizzati per eseguire operazioni matematiche sui dati.

| **Operatore** | **Nome**   | **Descrizione**                                              |
| ------------- | ---------- | ------------------------------------------------------------ |
| `&&`          | AND logico | Restituisce `1` solo se **entrambe** le condizioni sono vere |
| \|\|          | OR logico  | Restituisce `1` se **almeno una** condizione è vera          |
| `!`           | NOT logico | Inverte il valore di verità (vero diventa falso e viceversa) |
